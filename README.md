# Rootnot Audio

Official Windows x64 installers and updates for Rootnot Audio plugins.

Download installers from [Releases](https://github.com/therootnot/rootnot-audio-releases/releases/latest).

## Products

| Product | Version in the first release | Formats |
| --- | --- | --- |
| Octavion | 1.9.1 | VST3, Standalone |
| rot | 1.2.2 | VST3, Standalone |
| Geiger Core | 0.9.0-beta | VST3, CLAP, Standalone |
| Rootnot Audio Manager | 1.0.0 | Windows x64 application |

Rootnot Audio Manager checks the latest published release, reads its `rootnot-audio.json` catalog, and verifies each downloaded installer's SHA-256 before launching it. Close your DAW and plugin instances before updating.

Geiger Core is currently a beta. Plugin source code and user presets are not included in this repository.
